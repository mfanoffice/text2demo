# 文案转演示素材工作台

> 源码仓库：https://github.com/mfanoffice/text2demo 

把一段口播文案变成可翻页、可逐步入场的演示动画，顺手生成视频标题、标签和三种比例的封面。
给**自己在本机用**：不上架、不上传、不投稿。

## 它解决什么

拍口播视频时，演示动画、标题、标签、封面这四件事通常要在四五个工具里来回搬。这个工作台把它们收在一条流程里：

| 步骤 | 你做什么 | 它做什么 |
|---|---|---|
| 1 文案 | 把口播稿整段粘进来 | 存本机，不改你的字 |
| 2 分镜 | 点「大模型分镜」 | 模型**每次现场设计**每页版式与图示；风格（色板/网格/字号/缓动/安全区）由外壳固定 |
| 3 出演示 | 选主题，点「生成演示」 | 本机编译成单文件 HTML（零依赖），并逐页量一遍：越界、撞字幕区、缺入场动画、空页 |
| 4 预览改稿 | 空格逐步入场，翻页看 | 预览就在右边；改完重新出片；**换主题秒级整套换装，不用重新分镜** |
| 5 标题标签 | 点「生成标题」，不满意点「换一批」 | 一批有吸引力的标题 + 标签 |
| 6 封面 | 选中一个标题（=提示词），可补一句画面描述 | 点「生成封面图」：封面设计**完全交给文生图模型**（OpenAI Image 兼容，单独配置），按 16:9 / 4:3 / 3:4 各出一张，本地裁成精确比例，可下载 |


## 在 DSH Desktop 里怎么打开

工作台在 DSH 里的入口是**模式切换**，不是「工作台」列表里点开：

1. 左侧栏顶部、「新会话」下面那一行：左边是「工作台」按钮（打开工作台主页/列表），**右边**是显示当前模式的按钮（默认写着「标准模式」）。
2. 点**右边那个模式按钮** → 菜单「选择会话模式」里选 **演示动画工作台**。
3. 中间出现「开始使用演示动画工作台」时，点「新建工作区并开始对话」（或选一个已有工作区）。新会话会自动关联这个工作台。
4. 右侧出现工作台面板，顶部五个页签：文案 / 分镜 / 演示 / 标题 / 封面。

第一次用先点「载入示例」看整体效果，或去「设置」页填自己的模型接口（OpenAI 兼容，可点「测试连接」列出模型名）。

## 数据放在哪

**全部在浏览器 localStorage 里**（分镜、标题、封面文案、模型设置），服务端不落盘、不建目录、不删你的东西。卸载本工作台不会动这些数据；要清掉就在面板里删或清浏览器存储。

模型密钥同样只存在 localStorage，只在你要用时随请求发给**你自己填的接口**。本工作台的服务端只做转发，不写日志、不缓存。

## 模型接口（两套，互不影响）

- **对话模型**（分镜/标题）：「设置大模型」填 `base_url`（OpenAI 兼容，如 `https://api.deepseek.com/v1`）、模型名、密钥。
  分镜请求走**流式**：按钮上实时显示「版式设计 Ns · 已收 N 字 · 约 N 页」，静默超时才算失败，长文案不再被超时掐死。
- **文生图模型**（封面）：封面页签里「设置图像模型」单独填——OpenAI Image 兼容（`{base}/images/generations`），
  如 `https://api.openai.com/v1` + `gpt-image-1` / `dall-e-3`。可填风格后缀（自动接在提示词后）。
  「测试连接」只读 `/models` 列模型名，**不烧图**。返回形状容错（b64_json / url / 多种网关变体），
  gpt-image-1 拒绝 `response_format` 时会自动去掉参数重发。

面板运行在 Harness 页面里（同源 http），浏览器直连外部接口会被跨域拦；所以工作台的所有出网请求都走本插件的本机转发接口 `/api/deck-workbench/forward`。
转发只放行三类上游路径：`/chat/completions`、`/models`、`/images/generations`，且只转发 `authorization` / `content-type` / `accept` 三个请求头。

## 包结构

```
package.json            npm 与 DSH 插件声明（dsh.bundle.patch + dsh.client）
cordis.patch.yml        把服务端入口插入 profile 插件树
dsh/plugin.js           服务端入口：发界面 + 受限转发
lib/client.js           客户端入口：向 Desktop 注册业务面板
assets/workbench.html   工作台界面（由 scripts/build-assets.mjs 生成）
assets/tools/*.js       三个引擎：分镜编译 / 封面渲染 / 模型客户端
scripts/build-assets.mjs  从 keynote-workbench/ 复制界面与引擎
scripts/check-package.mjs 本包自检（规范第 3 节必须项）
scripts/stream-selftest/  流式回归测试：node scripts/stream-selftest/run.mjs
```

界面与引擎的源码只有一份，在包目录同级的 `keynote-workbench/`。改完源码跑
`node scripts/build-assets.mjs` 再打包；`pnpm pack` 的 `prepack` 也会自动跑一遍。

## 安装与卸载

安装（本机 profile 为 `web`）：

```bash
pnpm pack                                    # 产出 dsh-deck-workbench-1.0.0.tgz
dsh plugin --profile web add --config.auto-install-peers=false ./dsh-deck-workbench-1.0.0.tgz
```

装完重启 Harness，在「已安装的工作台」里会出现本工作台，左侧入口直接打开。
卸载：`dsh plugin --profile web remove dsh-deck-workbench`（本地工作台不删除任何业务数据）。

## 已知边界

- **工作台身份用的是本机占位仓库地址** `https://github.com/dsh-local/dsh-deck-workbench`：Desktop 用它解析工作台身份（owner/repo）。本工作台不上架，这个地址只在本机生效；以后真要发布，换仓库地址等于换身份，需要按规范处理已有会话归属。
- 面板复用工作台原有的整套界面（同源 iframe），没有为 DSH 重画一套 UI。
- 业务面板固定在右侧、宽度 0.7：工作台界面本身是「编辑区 + 预览区」双栏，窄了不好用。
- 业务面板必须声明 `embedded: true`（宿主未写进规范文档的字段）：它让宿主把面板容器从「带内边距的可滚动块」
  换成「flex 列 + padding 0」，业务界面才能拿到 `flex:1/min-height:0` 撑满面板。少了它，全高界面会塌成 0 高度、面板空白。
- **分镜走流式，标题走一次性**。分镜一次要让模型给 7–9 页现场写 HTML，输出量大，非流式时
  上游在整篇写完之前不发任何字节，链路上任何一层的「静默超时」都会先开火（表现为 504/502）。
  现在分镜用 `stream: true`：模型吐一块面板就收一块，按钮上实时显示「已收 N 字 · 约 N 页」。
  超时的含义也随之从「总时长」变成「静默时长」（15 秒没有任何字节才放弃，上限 600 秒）。
  标题、标签、连接探测仍走一次性请求——它们体量小，没必要复杂化。
- 转发链三层都必须是**逐块透传**：`tools/ai.js`（客户端解析）→ `dsh/plugin.js` 的 `/forward`
  → `keynote-workbench/tools/local-proxy.py`。任何一层改回「收完再吐」，流式就白做。
  这三层有回归测试：`node scripts/stream-selftest/run.mjs`（不联网、不花 token）。
- 分镜请求不带 `max_tokens`，输出长度由上游网关的默认值决定。若出现「分镜只回来一半、
  JSON 解析失败」，那是被网关默认上限截断了，不是超时。

## 视觉主题（8 款）

演示页签里「生成演示」按钮旁选主题，存进分镜数据（`SB.theme`），导出/导入分镜 JSON 会带着走。
默认 Keynote 浅色，不选就和以前完全一样。

| 主题 | 底子 | 适合 |
|---|---|---|
| Keynote 浅色 | 系统灰 + 白卡 + Apple 蓝 | 通用默认 |
| 暗夜 Dark | 近黑 + 发光描边 | 夜间、极客话题 |
| 极夜蓝 | 深蓝夜空 + 极光顶条 | 深度解读、架构原理 |
| 纸墨 Mono | 米白纸 + 唯一朱红强调 | 观点/评论向，文字即主角 |
| 暮光霓虹 | 紫夜 + 霓虹渐变阴影 | AI/潮流/互联网话题 |
| 暖阳奶油 | 奶油底 + 暖棕 + 大圆角 | 生活/好物/教育 |
| 石墨工业 | 中性灰 + 发丝线直角卡片 + 密网格 | 硬件/工程/数据 |
| 深海极光 | 墨绿深底 + 青碧极光条 | 数据/科技/自然 |

原理：整套视觉 = 一组 CSS 变量（`--bg`/`--ink`/`--card`/`--shadow`/网格/安全区压纱…），
分镜阶段发给模型的规范强制它**只用变量、禁止硬编码色值**——所以生成之后反悔，
换主题重新点「生成演示」秒级换装，**不用重新分镜**。暗色主题的卡片层次靠发光描边（投影在暗底上无效），
安全区会自动压一层黑纱提示字幕位。语义色纪律 8 套不变：蓝=主强调/绿=肯定/橙=注意/红=风险。
